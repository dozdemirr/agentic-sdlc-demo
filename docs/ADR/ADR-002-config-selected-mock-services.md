# ADR-002: Configuration-Selected Mock or Database Services

- **Status:** Observed; rationale is [INFERRED].
- **Decision:** The Web Forms, MVC 5, and ported applications select either a mock catalog service or a database-backed catalog service through a configuration flag read during application setup. (Sources: `/eShopLegacyWebFormsSolution/src/eShopLegacyWebForms/Global.asax.cs`; `/eShopLegacyWebFormsSolution/src/eShopLegacyWebForms/Modules/ApplicationModule.cs`; `/eShopLegacyMVCSolution/src/eShopLegacyMVC/Global.asax.cs`; `/eShopLegacyMVCSolution/src/eShopLegacyMVC/Modules/ApplicationModule.cs`; `/eShopLegacyMVCSolution/eShopPorted/Startup.cs`; `/eShopLegacyMVCSolution/eShopPorted/Modules/ApplicationModule.cs`.)
- **Context:** The checked-in default is mock data for Web Forms and `eShopPorted`, but database-backed data for MVC 5. When mock mode is disabled, the web startup paths register SQL-backed contexts and the corresponding initializers. (Sources: `/eShopLegacyWebFormsSolution/src/eShopLegacyWebForms/Web.config`; `/eShopLegacyMVCSolution/eShopPorted/appsettings.json`; `/eShopLegacyMVCSolution/src/eShopLegacyMVC/Web.config`; `/eShopLegacyWebFormsSolution/src/eShopLegacyWebForms/Global.asax.cs`; `/eShopLegacyMVCSolution/src/eShopLegacyMVC/Global.asax.cs`; `/eShopLegacyMVCSolution/eShopPorted/Startup.cs`.)
- **Consequences:** The selected provider is an environment/configuration concern rather than a different HTTP contract. The three applications do not share a common data-provider registration implementation, and their defaults are not uniform. (Sources: `/eShopLegacyWebFormsSolution/src/eShopLegacyWebForms/Modules/ApplicationModule.cs`; `/eShopLegacyMVCSolution/src/eShopLegacyMVC/Modules/ApplicationModule.cs`; `/eShopLegacyMVCSolution/eShopPorted/Modules/ApplicationModule.cs`; `/eShopLegacyWebFormsSolution/src/eShopLegacyWebForms/Web.config`; `/eShopLegacyMVCSolution/src/eShopLegacyMVC/Web.config`; `/eShopLegacyMVCSolution/eShopPorted/appsettings.json`.)
